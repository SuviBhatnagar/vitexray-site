# Publishing notes

**Static hosting (recommended):** this site is three plain files plus `assets/` with no build step, so the cleanest path is to upload the whole `vitexray-site/` folder to any static host (Netlify drag-and-drop, Cloudflare Pages, GitHub Pages, Vercel, or S3 + CloudFront) and point `vitexray.com` at it with the host's DNS instructions. All internal paths are relative, the favicon and OG image are local (`assets/`), and the only external call is Google Fonts, which falls back to the system font stack if blocked. After deploy, confirm `https://vitexray.com/assets/og-image.png` resolves so link previews work. **Wix:** Wix won't let you replace its page with your own HTML/CSS/JS. Its "Embed HTML / Custom Code" element renders your code inside a sandboxed iframe on a Wix page, so the sticky header, smooth in-page scrolling, anchor links, `mailto:` form behaviour and responsive sizing are all limited to that frame (fixed height, double scrollbars on mobile, no page-level SEO from the iframe's `<title>`/meta, and Wix's own header/footer still wrap it). Wix Velo can't host arbitrary static files at the root either. If the domain has to stay on Wix, the practical choices are (a) rebuild the design natively in the Wix Editor/Studio, using this file as the spec (colors `#0B1220`/`#2DD4BF`, Manrope + Inter, the same section order and copy), or (b) host this static site elsewhere and connect `vitexray.com` (or a subdomain such as `www`) to that host instead of Wix.
